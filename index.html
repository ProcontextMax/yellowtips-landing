Verificación legal

Detecta citas fabricadas y citas a derecho derogado (dead law). Verifica existencia, relevancia y temporalidad.

Preguntas frecuentes

Lo que necesitas saber antes de empezar.

¿Qué países cubren?

México, Colombia, Argentina, Chile, Perú y España. Estamos añadiendo más países de LATAM progresivamente.

¿Cómo se integra con mi agente de IA?

Es una API REST estándar. Haces un POST con tu API key y recibes JSON. Funciona con cualquier LLM: OpenAI, Claude, Gemini, Llama, o tu agente custom.

¿Qué pasa si la cita no está en su base de datos?

Devuelve status: partial con existence_check: not_found. No inventamos una respuesta. Preferimos decir "no puedo verificar" antes que arriesgar una cita falsa.

¿Puedo usar la API en producción?

Sí. El plan Free es para desarrollo. Los planes Starter y Pro incluyen SLA y soporte para producción.

¿Cómo cancelo mi suscripción?

Desde tu dashboard en cualquier momento. Sin preguntas, sin penalización. Sigues teniendo acceso hasta el final del período pagado.
